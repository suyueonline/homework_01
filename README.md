# 平台闯关 - 薇斯纳冒险 (Godot 4 平台跳跃小游戏)

基于 Godot 4.6 引擎开发的 2D 像素风平台跳跃闯关游戏。游戏角色为原神角色「薇斯纳（Vesna）」，拥有定制的完整动作图集与专属技能体系。

---

## 🎮 游戏操作控制

| 按键 | 功能操作 | 说明 |
| :--- | :--- | :--- |
| **A / D** | 水平奔跑 | 角色转向并播放 10 帧轻盈跑步循环动画 |
| **W / 空格** | 跳跃 | 地面起跳，滞空时仙子之翼自然舒展 |
| **双击 空格** | 开关飞行模式 | 快速双击进入自由飞行巡游，克服重力悬浮 |
| **飞行状态 W / S**| 上升 / 俯冲 | 飞行模式下垂直上升或快速下潜 |
| **Shift** | 冲刺飞行 (Dash) | 展开仙子双翼、伴随流光风痕高速向前冲刺（冷却 0.6s） |
| **J** | 普通攻击  | 挥动单手灵剑轻击斩，带星辉特效 |
| **E** | 元素战技  | 第一段突刺，（冷却 1.2s） |

## 🌟 核心机制与架构设计

### 1. 角色控制器 (`CharacterBody2D`)
- 采用 `move_and_slide()` 驱动运动学物理判定，避免刚体惯性发飘和瓦片缝隙卡顿。
- 内置平滑加减速阻尼模型（`move_toward`）。
- 动画状态机优先级：`冲刺 > E技能 > 平A > 滞空飞行 > 地面奔跑 > 待机`。

### 2. 瓦片地图 (`TileMapLayer`)
- 使用 Godot 4.3+ 标准 `TileMapLayer` 分层搭建（地形基础层、装饰层）。
- 瓦片物理层配置碰撞多边形，实现实体地面阻挡。

### 3. 碰撞与交互系统 (`Area2D`)
- **双排尖刺 (`Hazard`)**：触碰致命陷阱即刻判定受击并在起点安全重生。
- **金币 (`Collectible`)**：触碰自动触发拾取、计数并销毁。
- **弹簧 (`Spring`)**：踩中受强力反冲弹射升空。
- **坠崖保护**：跌落场景下边界自动安全重置。

## 📂 项目结构说明

```text
├── assets/
│   ├── game/
│   │   ├── characters/       # 角色切片、完整图集与 vesna_frames.tres 动画资源
│   │   └── tilesets/         # 瓦片图集与物理碰撞层配置
│   └── kenney/               # 场景通用美术资源
├── scenes/
│   ├── main.tscn             # 游戏主关卡场景（摄像机、地形、机关、金币）
│   ├── player.tscn           # 玩家角色预制体（AnimatedSprite2D、碰撞体、交互区）
│   └── prefabs/              # 尖刺、弹簧、金币、木箱等各类机关预制体
├── scripts/
│   └── player_controller.gd  # 核心角色控制脚本
├── export_presets.cfg        # 游戏导出预设配置
└── project.godot             # 引擎全局配置与输入按键映射
```
